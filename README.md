# 동굴바리 주짓수 토너먼트

**Donggulbari Jiu-Jitsu Tournament · Prototype v1.0**

동굴바리가 예선, 준결승, 결승에서 세 AI 선수를 꺾고 챔피언에 도전하는 캐주얼 2D 웹게임입니다. 포지션을 만들고 스태미나를 관리하며 암바·초크 또는 점수로 승리하세요. HTML, CSS, JavaScript와 Canvas만 사용하며 외부 라이브러리, 계정, 게임 서버가 필요 없습니다.

## 실행 방법

저장소를 다운로드한 뒤 `index.html`을 브라우저에서 엽니다. 모든 리소스가 상대 경로로 연결되어 인터넷 연결 없이도 플레이하도록 구성했습니다.

개발 시 정적 웹서버로도 실행할 수 있습니다. Python이 설치되어 있다면 저장소 폴더에서:

```sh
python3 -m http.server 8000
```

브라우저 주소창에 `http://localhost:8000`을 입력합니다. 정적 서버는 개발 편의용이며 게임 자체에 서버가 필요한 것은 아닙니다.

## 조작 방법

START 버튼으로 예선을 시작합니다. 화면 버튼은 PC 클릭과 모바일 터치를 모두 지원합니다. 사용할 수 없는 기술, 스태미나가 부족한 기술은 비활성화됩니다. 한 번 행동한 후 약 0.9초의 준비 시간이 있습니다.

| 키 | 기술 | 사용 상황 |
| --- | --- | --- |
| 1 | 테이크다운 | 스탠딩 |
| 2 | 가드 패스 | 가드 상위 |
| 3 | 스윕 | 가드 하위 |
| 4 | 마운트 이동 | 사이드 상위 |
| 5 | 백 컨트롤 | 사이드 상위 |
| 6 | 암바 / 초크 | 마운트 / 백 상위 |
| 7 | 탈출 | 모든 하위 포지션 |
| 8 | 방어 / 회복 | 모든 포지션 |
| P | 일시정지 / 계속 | 경기 중 |
| Enter | 시작 / 다음 경기 / 재도전 | 결과 화면 (버튼에 포커스가 있으면 해당 버튼 실행) |

도움말을 열거나 다른 탭으로 이동하면 경기가 일시정지됩니다. 계속하기 버튼으로 재개합니다. 모바일에서는 화면을 세로로 스크롤해 기술 버튼을 사용할 수 있습니다.

## 주요 기술과 규칙

```text
스탠딩 → 테이크다운 → 가드 상위 → 가드 패스 → 사이드 컨트롤
                                             ├→ 마운트 → 암바
                                             └→ 백 컨트롤 → 초크
가드 하위 → 스윕 → 가드 상위
마운트 / 백 하위 → 탈출 → 사이드 하위 → 탈출 → 가드 하위 → 탈출 → 스탠딩
```

- 테이크다운·스윕 **2점**, 가드 패스 **3점**, 마운트·백 컨트롤 **4점**.
- 서브미션 성공은 점수에 관계없이 즉시 승리입니다.
- 경기당 **75초**. 시간이 끝나면 높은 점수가 승리합니다. 동점이면 현재 경기를 다시 치릅니다.
- 같은 상위 유지 구간에서 이미 득점한 포지션을 되찾아도 추가 점수를 주지 않습니다. 스윕으로 상하위가 바뀌거나 스탠딩으로 돌아가면 득점 기록이 초기화됩니다.
- 공격마다 스태미나를 소비하며, 낮은 스태미나는 성공률을 낮춥니다. 기술 버튼에 현재 성공률과 비용이 표시됩니다.
- 스태미나는 초당 2.2씩 회복됩니다. 방어는 추가로 18을 회복하고 상대의 다음 공격 성공률을 25%p 낮춥니다. 공격하면 자신의 방어 자세가 해제됩니다.
- 결승으로 갈수록 AI의 기술 성공률과 행동 속도가 높아집니다. AI는 하위에서 스윕·탈출, 상위에서 포지션 이동·서브미션, 저스태미나에서 회복을 선택합니다.
- 패배하면 예선부터 재도전합니다. 다음 경기에는 스태미나·점수·시간이 초기화됩니다. 결승에서 승리하면 트로피와 챔피언 화면을 표시합니다.

## GitHub Pages 배포

1. 이 파일들을 `YunSangYeong/jiujitsu-game` 저장소의 `main` 브랜치 루트에 커밋하고 푸시합니다.
2. GitHub 저장소에서 **Settings → Pages**를 엽니다.
3. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치는 **main**, 폴더는 **/ (root)**로 선택하고 **Save**합니다.
5. 배포 완료 후 `https://yunsangyeong.github.io/jiujitsu-game/`에서 플레이할 수 있습니다.

별도 빌드가 필요 없습니다. 티스토리에는 배포된 게임 링크와 소개·스크린샷을 게시하면 됩니다.

## 파일 구조

- `index.html`: 시작·경기·결과 화면 및 접근성 마크업
- `style.css`: 도장 분위기, PC·모바일 반응형 스타일
- `engine.js`: 포지션, 확률, 점수, 스태미나, AI와 승패 규칙 (DOM과 분리)
- `graphics.js`: 기술별 관절 자세와 중간 프레임 보간 (Canvas와 분리)
- `audio.js`: Web Audio API로 합성하는 효과음과 음소거 관리
- `game.js`: 화면 갱신, 입력, 게임 루프, Canvas 캐릭터와 경기장
- `tests/engine.test.js`: Node.js 기본 테스트 러너를 사용하는 게임 규칙 테스트
- `tests/graphics.test.js`: 기술별 자세·보간·이벤트 검증
- `tests/browser.test.cjs`: 선택적으로 실행하는 Playwright 브라우저 회귀 테스트

## 테스트

Node.js 18 이상에서 규칙 테스트 (별도 패키지 설치 없음):

```sh
node --test tests/*.test.js
```

브라우저 테스트는 개발자 검증용입니다. 게임 실행에는 Playwright가 필요 없습니다. Linux 환경에서 Chromium이 설치되어 있다면 다음과 같이 임시 폴더에만 테스트 의존성을 설치할 수 있습니다:

```sh
npm install --prefix /tmp/jiujitsu-browser-tests --cache /tmp/jiujitsu-npm-cache playwright@1.58.2 --no-audit --no-fund
NODE_PATH=/tmp/jiujitsu-browser-tests/node_modules CHROMIUM_PATH=/usr/bin/chromium node tests/browser.test.cjs
```

테스트는 자체 임시 정적 서버를 시작하고 종료합니다. 우승까지의 UI 검증에는 고정 난수와 정지된 AI 행동 타이머를 사용해 결과를 재현합니다. AI 선택·일반 난수 경기 종료는 별도 규칙 테스트로 확인합니다. PC 키보드, 모바일 터치, 320·360·390·768·1280px 너비, 패배·동점·재시작·일시정지도 확인합니다.

### v1.0 검증 결과

- 게임 규칙·그래픽·오디오 테스트 18개 통과, 120회 무작위 경기 정상 종료 확인.
- Chromium 정적 서버 실행: 3라운드 진행, 암바·초크 승리, 트로피, 판정 패배, 동점 재경기, 재시작, 키보드, 일시정지 확인.
- 모바일 에뮬레이션: 실제 터치 입력으로 테이크다운·패스 확인, 320~1280px 가로 넘침 없음, 터치 버튼 높이 44px 이상.
- 브라우저 런타임 오류 없음. 실제 iOS/Safari와 Android 실기기는 아직 확인하지 않았습니다.
- 클라우드 Chromium 정책이 `file://` 탐색을 차단하여 로컬 파일 직접 열기는 이 환경에서 검증하지 못했습니다. 정적 서버 실행은 검증했으며 코드는 모듈 import·fetch 없이 일반 스크립트로 구성했습니다.

## 단순화한 부분 / 다음 개선 후보

실제 주짓수 규칙 전체를 재현하지 않습니다. 가드 종류, 3초 포지션 유지, 어드밴티지·페널티, 세부 서브미션 방어는 생략했습니다. 암바와 초크는 별도 미니게임 없이 확률로 결정됩니다. 그래픽은 자세가 바뀌는 단순 도복 캐릭터이며 진행 상황 저장·온라인 대전은 없습니다.

다음 단계에서는 실제 플레이 피드백으로 난이도와 회복량을 조정하고, 더 정교한 애니메이션·배경음악, 다양한 상대 성향, 짧은 조작 튜토리얼을 추가할 수 있습니다.

## 기술 그래픽 개선

테이크다운은 몸을 낮춰 넘어뜨리기, 가드 패스는 다리 옆으로 돌아가기, 스윕은 몸을 회전해 상하위 뒤집기, 탈출은 프레임을 만들고 거리 벌리기로 표현합니다. 마운트와 백 진입도 중간 자세를 거칩니다. 암바는 팔을 두 손으로 잡고 다리로 제어하는 자세, 초크는 뒤에서 목을 감싸는 자세로 구분하며 제어 부위를 표시합니다.

성공·실패와 기술 이름이 매트 위에 표시됩니다. 실패하면 상대가 방어하고 원래 자세로 돌아옵니다. 방어 중에는 실드가 표시됩니다. AI도 동일한 동작을 사용하며, 서브미션 성공 시 탭 장면을 약 1.25초 보여준 뒤 결과 화면으로 이동합니다. 일시정지하면 애니메이션도 멈춥니다. 기기의 움직임 줄이기 설정에서는 자세 전환을 즉시 표시하고 이동 궤적을 생략합니다.

자세는 기술을 알아보기 쉽게 만든 단순한 2D 표현입니다. 기존 점수·확률·스태미나 규칙은 유지했습니다.

## 효과음

START를 누르면 소리가 활성화됩니다. 시작 종, 도복 움직임, 매트 충격, 기술 성공·방어, 회복, 서브미션 탭, 승패·우승 효과음을 제공합니다. 충격·탭 소리는 애니메이션 타이밍에 맞춰 재생됩니다. 상단의 **소리 켜짐 / 소리 꺼짐** 버튼으로 전환하며 설정은 브라우저에 저장합니다. 일시정지하거나 다른 탭으로 이동하면 재생 중인 효과음도 즉시 멈춥니다.

외부 음원 다운로드 없이 Web Audio API로 짧은 효과음을 합성합니다. 음악은 포함하지 않았습니다. 지원되지 않는 브라우저에서는 소리 없이 게임을 계속할 수 있습니다. 휴대폰에서 소리가 안 들리면 미디어 볼륨과 기기의 무음 설정을 확인하세요.

Chromium에서 PC 클릭·모바일 터치 후 오디오 활성화, 음소거 설정 유지, 일시정지 중 무음, 12종 효과음의 실제 오디오 샘플 생성과 클리핑 없는 출력을 검증했습니다. 실제 기기 스피커와 iOS Safari 청음은 별도 확인이 필요합니다.

### 모바일 소리 복구

모바일 오디오 초기화를 실제 터치 해제 시점에 수행하며, Safari의 `interrupted` 상태와 닫힌 오디오 컨텍스트도 복구합니다. 오디오 활성화 실패는 소리 버튼의 설명에 표시하며 **소리 테스트**로 재시도할 수 있습니다. 상단 **소리 테스트**를 누르면 음소거 설정을 해제하고 테스트 종을 재생합니다. 일시정지 중에도 이 버튼으로만 테스트음을 들을 수 있습니다.

소리가 작게 들리는 휴대폰을 위해 기본 출력도 높였습니다. 리소스 URL 버전을 갱신해 예전 스크립트가 캐시에 남는 경우를 줄였습니다. Safari 상태 복구·재시도는 모의 오디오 컨텍스트 테스트로, 실제 터치와 테스트 버튼은 Chromium 모바일 에뮬레이션으로 검증했습니다. 실제 휴대폰에서 소리가 들리는지는 추가 확인이 필요합니다.

## 캐릭터 입체감 개선

2D Canvas와 기존 포지션·기술을 유지하면서 도복과 팔다리의 원통형 명암, 둥근 얼굴·손발, 두께 있는 깃·벨트, 옷 주름과 겹침 그림자를 추가했습니다. 캐릭터별 매트 그림자로 바닥 접촉도 표현합니다. 3D 라이브러리나 모델 다운로드는 없습니다.

모바일 소리 버튼은 오디오 권한 상태와 관계없이 터치할 때마다 켜짐/꺼짐이 전환됩니다. 버튼의 크기를 고정하고 상단 터치 영역을 3등분해 글자 변경으로 대상이 움직이지 않게 했습니다. 소리 재활성화는 별도 **소리 테스트** 버튼을 사용합니다. 320px 모바일에서 오디오 활성화를 강제로 보류한 상황에서도 연속 터치 전환과 버튼 위치 유지를 검증합니다.

## 경기 전 선수 소개

START와 다음 경기·재도전 버튼을 누르면 각 경기 전에 약 7.4초의 소개 장면이 재생됩니다. 청 코너 동굴바리 → 홍 코너 AI 상대 → 두 선수 준비 순서로 이름·특징과 소개 문구를 표시하며, 스포트라이트·등장·손 인사와 짧은 팡파르를 함께 보여줍니다. 경기 시간·스태미나·AI는 소개가 끝날 때까지 움직이지 않습니다.

기기에 한국어 음성 합성 음성이 있으면 장내 아나운서처럼 선수 이름을 읽습니다. 한국어 음성이 없으면 자막과 효과음으로 소개하며 경기 진행은 동일합니다. 음소거하면 음성과 효과음이 모두 꺼집니다. 별도 음성 파일이나 서버는 사용하지 않습니다.

**소개 건너뛰기**를 클릭·터치하면 바로 경기를 시작합니다. P 키와 일시정지 버튼, 탭 이동 시 소개도 멈춥니다. 움직임 줄이기 설정에서는 등장 이동과 손 인사를 생략합니다.
