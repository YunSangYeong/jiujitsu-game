# 동굴바리 주짓수 토너먼트

**Donggulbari Jiu-Jitsu Tournament · Prototype v1.0**

동굴바리가 예선, 준결승, 결승에서 세 AI 선수를 꺾고 챔피언에 도전하는 캐주얼 2D 웹게임입니다. 포지션을 만들고 스태미나를 관리하며 암바·초크 또는 점수로 승리하세요. HTML, CSS, JavaScript와 Canvas만 사용하며 외부 라이브러리, 계정, 게임 서버가 필요 없습니다.

## 실행 방법

저장소를 다운로드한 뒤 `index.html`을 브라우저에서 엽니다. 모든 리소스가 상대 경로로 연결되어 인터넷 연결 없이도 플레이하도록 구성했습니다.

개발 시 정적 웹서버로도 실행할 수 있습니다. Python이 설치되어 있다면 저장소 폴더에서:

```sh
python3 -m http.server 8000
```

브라우저 주소창에 `http://localhost:8000`을 입력합니다. 정적 서버는 개발 편의용이며 게임 자체에 서버가 필요한 것은 아닙니다.

## 조작 방법

START 버튼으로 예선을 시작합니다. 화면 버튼은 PC 클릭과 모바일 터치를 모두 지원합니다. 사용할 수 없는 기술, 스태미나가 부족한 기술은 비활성화됩니다. 한 번 행동한 후 약 0.9초의 준비 시간이 있습니다.

| 키 | 기술 | 사용 상황 |
| --- | --- | --- |
| 1 | 테이크다운 | 스탠딩 |
| 2 | 가드 패스 | 가드 상위 |
| 3 | 스윕 | 가드 하위 |
| 4 | 마운트 이동 | 사이드 상위 |
| 5 | 백 컨트롤 | 사이드 상위 |
| 6 | 암바 / 초크 | 마운트 / 백 상위 |
| 7 | 탈출 | 모든 하위 포지션 |
| 8 | 방어 / 회복 | 모든 포지션 |
| P | 일시정지 / 계속 | 경기 중 |
| Enter | 시작 / 다음 경기 / 재도전 | 결과 화면 (버튼에 포커스가 있으면 해당 버튼 실행) |

도움말을 열거나 다른 탭으로 이동하면 경기가 일시정지됩니다. 계속하기 버튼으로 재개합니다. 모바일에서는 화면을 세로로 스크롤해 기술 버튼을 사용할 수 있습니다.

## 주요 기술과 규칙

```text
스탠딩 → 테이크다운 → 가드 상위 → 가드 패스 → 사이드 컨트롤
                                             ├→ 마운트 → 암바
                                             └→ 백 컨트롤 → 초크
가드 하위 → 스윕 → 가드 상위
마운트 / 백 하위 → 탈출 → 사이드 하위 → 탈출 → 가드 하위 → 탈출 → 스탠딩
```

- 테이크다운·스윕 **2점**, 가드 패스 **3점**, 마운트·백 컨트롤 **4점**.
- 서브미션 성공은 점수에 관계없이 즉시 승리입니다.
- 경기당 **75초**. 시간이 끝나면 높은 점수가 승리합니다. 동점이면 현재 경기를 다시 치릅니다.
- 같은 상위 유지 구간에서 이미 득점한 포지션을 되찾아도 추가 점수를 주지 않습니다. 스윕으로 상하위가 바뀌거나 스탠딩으로 돌아가면 득점 기록이 초기화됩니다.
- 공격마다 스태미나를 소비하며, 낮은 스태미나는 성공률을 낮춥니다. 기술 버튼에 현재 성공률과 비용이 표시됩니다.
- 스태미나는 초당 2.2씩 회복됩니다. 방어는 추가로 18을 회복하고 상대의 다음 공격 성공률을 25%p 낮춥니다. 공격하면 자신의 방어 자세가 해제됩니다.
- 결승으로 갈수록 AI의 기술 성공률과 행동 속도가 높아집니다. AI는 하위에서 스윕·탈출, 상위에서 포지션 이동·서브미션, 저스태미나에서 회복을 선택합니다.
- 패배하면 예선부터 재도전합니다. 다음 경기에는 스태미나·점수·시간이 초기화됩니다. 결승에서 승리하면 트로피와 챔피언 화면을 표시합니다.

## GitHub Pages 배포

1. 이 파일들을 `YunSangYeong/jiujitsu-game` 저장소의 `main` 브랜치 루트에 커밋하고 푸시합니다.
2. GitHub 저장소에서 **Settings → Pages**를 엽니다.
3. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치는 **main**, 폴더는 **/ (root)**로 선택하고 **Save**합니다.
5. 배포 완료 후 `https://yunsangyeong.github.io/jiujitsu-game/`에서 플레이할 수 있습니다.

별도 빌드가 필요 없습니다. 티스토리에는 배포된 게임 링크와 소개·스크린샷을 게시하면 됩니다.

## 파일 구조

- `index.html`: 시작·경기·결과 화면 및 접근성 마크업
- `style.css`: 도장 분위기, PC·모바일 반응형 스타일
- `engine.js`: 포지션, 확률, 점수, 스태미나, AI와 승패 규칙 (DOM과 분리)
- `game.js`: 화면 갱신, 입력, 게임 루프, Canvas 캐릭터와 경기장
- `tests/engine.test.js`: Node.js 기본 테스트 러너를 사용하는 게임 규칙 테스트
- `tests/browser.test.cjs`: 선택적으로 실행하는 Playwright 브라우저 회귀 테스트

## 테스트

Node.js 18 이상에서 규칙 테스트 (별도 패키지 설치 없음):

```sh
node --test tests/engine.test.js
```

브라우저 테스트는 개발자 검증용입니다. 게임 실행에는 Playwright가 필요 없습니다. Linux 환경에서 Chromium이 설치되어 있다면 다음과 같이 임시 폴더에만 테스트 의존성을 설치할 수 있습니다:

```sh
npm install --prefix /tmp/jiujitsu-browser-tests --cache /tmp/jiujitsu-npm-cache playwright@1.58.2 --no-audit --no-fund
NODE_PATH=/tmp/jiujitsu-browser-tests/node_modules CHROMIUM_PATH=/usr/bin/chromium node tests/browser.test.cjs
```

테스트는 자체 임시 정적 서버를 시작하고 종료합니다. 우승까지의 UI 검증에는 고정 난수와 정지된 AI 행동 타이머를 사용해 결과를 재현합니다. AI 선택·일반 난수 경기 종료는 별도 규칙 테스트로 확인합니다. PC 키보드, 모바일 터치, 320·360·390·768·1280px 너비, 패배·동점·재시작·일시정지도 확인합니다.

### v1.0 검증 결과

- 게임 규칙 테스트 9개 통과, 120회 무작위 경기 정상 종료 확인.
- Chromium 정적 서버 실행: 3라운드 진행, 암바·초크 승리, 트로피, 판정 패배, 동점 재경기, 재시작, 키보드, 일시정지 확인.
- 모바일 에뮬레이션: 실제 터치 입력으로 테이크다운·패스 확인, 320~1280px 가로 넘침 없음, 터치 버튼 높이 44px 이상.
- 브라우저 런타임 오류 없음. 실제 iOS/Safari와 Android 실기기는 아직 확인하지 않았습니다.
- 클라우드 Chromium 정책이 `file://` 탐색을 차단하여 로컬 파일 직접 열기는 이 환경에서 검증하지 못했습니다. 정적 서버 실행은 검증했으며 코드는 모듈 import·fetch 없이 일반 스크립트로 구성했습니다.

## 단순화한 부분 / 다음 개선 후보

실제 주짓수 규칙 전체를 재현하지 않습니다. 가드 종류, 3초 포지션 유지, 어드밴티지·페널티, 세부 서브미션 방어는 생략했습니다. 암바와 초크는 별도 미니게임 없이 확률로 결정됩니다. 그래픽은 자세가 바뀌는 단순 도복 캐릭터이며 사운드·저장·온라인 대전은 없습니다.

다음 단계에서는 실제 플레이 피드백으로 난이도와 회복량을 조정하고, 타격감 있는 애니메이션·효과음, 다양한 상대 성향, 짧은 조작 튜토리얼을 추가할 수 있습니다.
